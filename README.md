## 简体中文

隐藏「开发者选项已开启」与「USB 调试已连接」。

**需要**：Android 8.1+、LSPosed、KernelSU 或 Magisk。

### 安装

1. 安装 APK，在 LSPosed 管理器里启用（作用域已内置为 `system`，无需勾选）。
2. 打开 USBHide → 导出安装包 → 文件落在 `Download/usbhide-enhance.zip`。
3. 在 KernelSU / Magisk 管理器里刷入该 zip。
4. **重启**，再打开 USBHide：两行都是绿的即生效。

---

## English

Hides "Developer options enabled" and "USB debugging connected".

**Requires**: Android 8.1+, LSPosed, KernelSU or Magisk.

### Install

1. Install the APK and enable USBHide in LSPosed Manager (scope `system` is built in).
2. Open USBHide → Export module → the zip lands in `Download/usbhide-enhance.zip`.
3. Flash that zip in KernelSU / Magisk Manager.
4. **Reboot**, then open USBHide: both lines green means it is working.
